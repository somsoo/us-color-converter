🧮 How the conversions work

  • HEX and RGB: a HEX code is three pairs of base-16 digits for red, green and blue (00 to FF, which is 0 to 255). Example: #1D4ED8 is rgb(29, 78, 216). Three-digit codes double each digit, and a fourth or eighth digit pair is opacity (CSS order #RRGGBBAA; Android writes #AARRGGBB instead).
  • HSL: hue in degrees around the color wheel, then saturation and lightness in percent, as defined for CSS in the W3C CSS Color Module Level 4.
  • HSV / HSB: the same hue, with saturation and value (brightness) instead of lightness. It is the model many design apps use in their color pickers.
  • CMYK: K = 1 − max(R′, G′, B′), then C = (1 − R′ − K) ÷ (1 − K), and the same for M with G′ and Y with B′, where R′, G′ and B′ are 0 to 1. This ignores inks and paper, so it is only an estimate.
  • Contrast ratio: each channel is divided by 255 and converted to linear light (divide by 12.92 at 0.04045 or below, otherwise ((c + 0.055) ÷ 1.055)^2.4). Relative luminance is 0.2126 R + 0.7152 G + 0.0722 B, and the ratio is (lighter + 0.05) ÷ (darker + 0.05).
  • Pass or fail: the unrounded ratio is compared with each threshold. The ratio on screen is cut to two decimals, never rounded up.

❓ Frequently asked questions

How do I convert HEX to RGB?

Split the six digits into three pairs and read each pair as a base-16 number. For #1D4ED8, 1D is 29, 4E is 78 and D8 is 216, so the color is rgb(29, 78, 216). A three-digit code doubles each digit, so #F80 is #FF8800. An eight-digit code such as #1D4ED880 adds opacity as the last pair; this tool uses the CSS order #RRGGBBAA.

What contrast ratio do I need?

WCAG 2.2 level AA asks for at least 4.5:1 for normal text and 3:1 for large text, which is at least 18 point, or 14 point bold. Level AAA asks for 7:1 and 4.5:1. Buttons, form borders, icons and other graphics need 3:1 against the colors next to them (Success Criterion 1.4.11, level AA).

How is the contrast ratio calculated?

Each color's relative luminance is 0.2126 R + 0.7152 G + 0.0722 B, where each sRGB channel is first converted from its 0 to 255 value to linear light. The ratio is the lighter luminance plus 0.05 divided by the darker luminance plus 0.05, from 1:1 to 21:1. This tool shows the ratio cut to two decimals, never rounded up, so a pair shown as 4.49:1 does not pass a 4.5:1 test.

Why do my CMYK numbers differ from my printer's?

This converter uses the simple formula that treats cyan, magenta and yellow as the opposites of red, green and blue, with black taken out first. Real printing uses color profiles for specific inks and paper, such as US Web Coated (SWOP), so a print shop's values can be quite different. Ask your printer for values made with their profile before you print.

How are transparent colors checked?

When your color has less than 100% opacity and is used as text, it is first blended with the background, the same way a browser draws it, and the blended color is checked. When a semi-transparent color is used as the background, what shows through depends on the page behind it, so the tool checks the fully opaque color and says so.
